## Less generic writing

A bio for a bakery should not sound like a bio for a software founder.

The same applies to captions, LinkedIn comments, product descriptions and SEO titles.

The tools have been designed to use relevant context, including the user's audience, subject, goal, tone and factual details.

## What changed

- More task specific instructions.
- Greater emphasis on user supplied information.
- Stronger controls against invented claims.
- Better handling of platform specific limits.
- Less unnecessary filler.
- Improved relevance to the user's selected purpose.

## One result worth using

Every AI generator now writes one complete result instead of several generic alternatives. Click Regenerate for a fresh take, or use Refine to ask for a specific change, like shorter or warmer.

## Also new

- An optional "Anything else?" box for your own instructions.
- Photo, PDF and text file uploads on the tools where they help. Uploads are only used to write the result and aren't stored.
- The SEO Title and Meta Description tools can read your page from its URL.
