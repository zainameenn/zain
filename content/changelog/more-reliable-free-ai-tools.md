## What's new

The free AI tools are faster and keep working when one AI service is busy.

- **Automatic fallback.** Each request tries a fast free model first. If it's busy, down or gives an unusable answer, the next free model takes over, and then the next.
- **Fair daily limits.** Everyone gets a small number of free generations a day, so the tools stay available for all visitors. Your details stay in the form if you hit the limit.
- **No double requests.** Clicking generate twice won't send the same request twice.
- **Private details stay out.** If you paste something like an API key, password, card number or email address, the tool asks you to remove it before anything is sent.

## Privacy

Only free AI services are used. We don't log what you type or what the tools write back.
