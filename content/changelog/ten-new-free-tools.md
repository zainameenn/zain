## What's new

Ten more free tools, each built for one job.

**Naming**

- [Etsy Shop Name Generator](/tools/etsy-shop-name-generator): one name that follows Etsy's rules, 4 to 20 letters and numbers.
- [Shopify Store Name Generator](/tools/shopify-store-name-generator): one brand name with a domain idea.
- [YouTube Channel Name Generator](/tools/youtube-channel-name-generator): one channel name with a handle idea.

**Content and search**

- [YouTube Shorts Script Generator](/tools/youtube-shorts-script-generator): one complete script with a hook, timed beats and an ending.
- [Negative Keyword Generator](/tools/google-ads-negative-keyword-generator): a reviewed list of negative keyword candidates with match types and risk levels, ready for CSV.
- [Search Intent Classifier](/tools/seo-search-intent-classifier): up to 25 keywords at once, each with an intent and a suggested page type.

**Calculators and utilities**

- [Etsy Offsite Ads Calculator](/tools/etsy-offsite-ads-calculator): profit after the 15% or 12% Offsite Ads fee, with break-even prices.
- [Shopify Profit Margin Calculator](/tools/shopify-profit-margin-calculator): gross and net margin, markup, break even and a target margin price.
- [Google Review Link Generator](/tools/google-review-link-generator): a direct review link and a QR code from your Place ID or review link.
- [LLMS.txt Generator](/tools/llms-txt-generator): a correctly structured llms.txt file you can copy or download.

## How they work

The six writing tools give one result you can edit, copy or regenerate. They never claim a name is available or that a keyword has search volume, because they can't know that.

The four calculators and utilities run entirely in your browser, with no AI and nothing sent anywhere.
