## What's new

**Five new free SEO tools.** Each one checks a real, public page and shows the evidence for every result:

- **Website SEO Checker:** checks one page's title, description, headings, canonical, indexing directives and more.
- **Website Metadata Extractor:** pulls every metadata tag from a page, or from HTML you paste.
- **Broken Link Checker:** tests up to 40 links on a page, and tells apart a broken link from a site that blocks automated checks.
- **Sitemap URL Status Checker:** tests the URLs in an XML sitemap for errors, redirects, noindex and canonicals pointing elsewhere.
- **Website Audit Tool:** crawls up to 15 pages of a site to find repeated issues such as duplicate titles.

**A new SEO tools directory** at /tools/seo groups every working SEO tool by the job it does.

**A fresh look for every free tool.** Tool pages now use Lora headings, Figtree text and the forest green and ivory palette.

More SEO tools that use live search data are built and will appear once their usage tracking is switched on.
