## Know where your traffic comes from

Sharing the same website link across several campaigns makes attribution more difficult.

The UTM Link Builder helps create tracking links by adding campaign source, medium, name and other relevant parameters to a destination URL.

Use the generated links in campaigns to make traffic sources easier to identify in supported analytics tools. It runs in your browser, so nothing you type is sent anywhere.
