## Make your Pins easier to understand

Pinterest combines visual discovery with search.

These tools help explain what a Pin contains and why it is relevant.

The [Title Generator](/tools/pinterest-title-generator) produces a focused title. The [Description Generator](/tools/pinterest-description-generator) adds context using the topic, target audience and relevant search terms.

Both tools should accurately represent the actual Pin.
