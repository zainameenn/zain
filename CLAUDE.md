## Rules for working on this site
- Change only what the current request asks for. Never touch graphics, images, illustrations, results, stats, testimonials, pricing amounts, FAQs, buttons, layout or other copy unless asked.
- Never refactor or tidy unrelated code. Report problems instead of fixing them.
- Never use em dashes or en dashes in site copy. No hyphens as punctuation.
- Never use the word "freelance" to describe Zain. Market comparisons about other freelancers and client reviews are fine.
- Each page has exactly one H1. Hero H1s have a regular part and an italic serif accent part, using the shared styles in app/HomeComponents/heading.ts.
- Every page's target keyword goes in its title, meta description, URL, H1 and the start of the first sentence.
- og:title, og:description and og:url always match the page's own title, description and canonical URL.
- Work on a branch. Never push to master without Zain's OK.
